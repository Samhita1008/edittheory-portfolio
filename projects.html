Edit Theory Concierge

A universal booking assistant for local businesses

Restaurants • Gyms • Salons • Parlours • Travel Agencies

CUSTOMER-FACING PRODUCT OVERVIEW

A customer picks a category, searches for a venue, books it, and gets a live-tracked confirmation — all through a React frontend backed by an n8n automation pipeline. Unlike my earlier agents, which automate a business's internal workflow, this is a product a business could hand directly to their customers.

WHAT IT DOES

  • → Discover: AI-assisted location extraction + venue search across multiple local categories.
  • → Book: Field validation, automated booking logging, and instant booking ID generation.
  • → Confirm: Automated venue contact dispatch and status resolution.
  • → Notify: Instant confirmation email with booking reference, calendar details, and itinerary.
  • → Status: Zero-refresh live polling for real-time booking status transitions.
⚙ ARCHITECTURE & DEMO DISCLOSURE PLUG-AND-PLAY READY

Intentional Architecture: Venue discovery and venue-confirmation both run on free/simulated data sources by design, disclosed clearly, with production integrations (Google Places, WhatsApp Business API) fully built and ready to activate once connected to real credentials.

This is an intentional design decision, not a limitation — the product is built to be handed to a client who plugs in their own accounts without vendor lock-in.

Restaurant Outreach AI System

Structured 8-point audit engine, bulletproof pipeline reliability, and customer-deployable packaging.

Audit Engine • Deduplication Shield • Decoupled Architecture

PRODUCT-READINESS MILESTONE: PROTOTYPE → DEPLOYABLE PRODUCT STANDALONE READY

Reworked the system from an internal workflow into a fully customer-deployable product. Completely decoupled all environment variables and API credentials from canvas logic, built a standardized Google Sheet template for client onboarding, authored an end-to-end setup guide, and centralized configuration so the engine operates independently of personal accounts. This serves as core technical preparation toward listing the package (actively exploring Google Cloud Marketplace).

SYSTEM UPGRADES & AUDIT WORKFLOW

  • → Structured 8-Point Audit Checklist: Replaced vague AI quality tags with an objective, deterministically evaluated inspection covering: (1) Site exists, (2) Loads correctly, (3) Mobile-friendly viewport, (4) Clear menu/services, (5) Visible contact info, (6) Online booking/ordering, (7) Modern UI layout, and (8) Technical console errors. Every classification is backed by a specific written reason.
  • → Graceful Website Error Boundaries: Built comprehensive exception handling for unreachable, timeout-prone, or DNS-failing domains. Instead of leads silently dropping mid-workflow, failures are trapped, categorized, and preserved in the CRM with clear status flags.
  • → Row-Matching & Deduplication Shield: Resolved Google Sheets row-matching synchronization race conditions and eliminated duplicate-email-send bugs by enforcing idempotent lead hashing before any Gmail API dispatch.
  • → Active Production LLM Migration: Migrated prompt execution off deprecated Groq models to current, supported production endpoints for deterministic pitch generation referencing audited site findings.
  • → Safety-First Dispatch & Alerts: Preserves manual approval gates before sending, respects mailbox health limits (15/hr), and forwards positive inbound replies to Telegram in real time.

Email Summary Agent

Triages your inbox every morning, before you open Gmail.

AGENT PURPOSE

Built my fifth automation agent: an Email Summary Agent that triages your inbox every morning, before you open Gmail. No dashboard. No scrolling. Open Telegram, know what needs you in 10 seconds.

SYSTEM FLOW

  • → 24h Inbox Scan: Pulls every email from the last 24 hours, not just unread.
  • → Noise Stripper: Filters out newsletter and promo noise before it hits the AI.
  • → Groq Triage: Groq reads each email and categorizes it: 🔴 needs reply today, 🟡 FYI, 🟢 can wait.
  • → One-Line Distillation: Writes a one-line summary per email, not the whole thread dumped.
  • → Telegram Dispatch: Sends one clean, sorted digest to Telegram every morning.
⚡ PRODUCTION POST-MORTEM

What made this hard: Keeping sender and subject data intact through the AI step without it getting lost or duplicated. Same fix as always: a Merge node in the right place.

This is built for founders drowning in inbox with no time to triage. Same system adapts to any niche where inbox fatigue is real, not just solo founders.

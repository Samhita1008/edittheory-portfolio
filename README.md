# Edit Theory — Portfolio

Source for [edittheory-portfolio.vercel.app](https://edittheory-portfolio.vercel.app/), the case-study site for **Edit Theory**, an AI automation practice for D2C brands and local businesses.

## What's here

A walkthrough of the agents built in [edit-theory-agents](https://github.com/Samhita1008/edit-theory-agents) and the standalone [Concierge](https://github.com/Samhita1008/edit-theory-concierge) product, each written up as a case study rather than a project list, what the problem was, what got built, what broke along the way.

## Stack

React · TypeScript · Vite · Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```

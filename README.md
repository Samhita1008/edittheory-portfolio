Source for [edittheory-portfolio.vercel.app](https://edittheory-portfolio.vercel.app/), the case-study site for **Edit Theory**, an AI automation practice for D2C brands and local businesses.

## What's here

A walkthrough of the agents built in [edit-theory-agents](https://github.com/Samhita1008/edit-theory-agents) and the standalone [Concierge](https://github.com/Samhita1008/edit-theory-concierge) product. Each is written up as a case study rather than a project list: what the problem was, what got built, and what broke along the way.

## How the site behaves

- **Opens on the logo.** Scrolling zooms through the letter T of "EDIT", then the page continues normally.
- **Quiet scroll motion.** Sections reveal as they enter view. A pinned process section walks through how a build runs. A giant wordmark slides sideways in the footer.
- **Respects reduced motion.** Animations switch off for people who ask their system for it.

## Palette

| Name | Hex | Use |
|---|---|---|
| Bordo | `#6C151E` | Primary dark surfaces |
| Green | `#0F3D3A` | Contrast sections |
| Cream | `#F5DABF` | Light surfaces, text on dark |

Type: Anton for the wordmark, Newsreader for headings, Hanken Grotesk for body text. All fonts are bundled, nothing loads from a CDN.
